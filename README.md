### 👋 About Me

백엔드 개발을 시작으로 **데이터베이스 설계, 소프트웨어 검증, 업무 자동화**를 경험하며 IT 시스템 전반으로 관심을 넓혀왔습니다.  
기능 구현뿐 아니라 **요구사항과 데이터의 흐름을 파악하고, 반복되는 업무를 더 효율적으로 개선하는 과정**에 관심이 있습니다.  
현재는 **기업 정보시스템(ERP), IT 운영, 데이터 관리 및 프로세스 개선** 역량을 쌓아가고 있습니다.
