## ABOUT ME

<div align="center">

백엔드 개발과 데이터베이스 설계를 시작으로, 소프트웨어 검증과 업무 자동화까지 경험하며 IT 시스템을 다양한 관점에서 이해해 왔습니다.

기능을 구현하는 것에 그치지 않고 **요구사항과 데이터 흐름을 구조적으로 파악하고, 반복되는 업무를 더 효율적으로 개선하는 과정**에 관심이 있습니다. 팀 프로젝트에서 사용자 인증과 데이터 관리를 구현했고, 소프트웨어 V&V 업무에서는 요구사항과 설계 산출물을 검토하며 문서 비교 자동화를 시도했습니다.

현재는 이러한 경험을 바탕으로 **기업 정보시스템(ERP), IT 운영, 데이터 관리 및 프로세스 개선** 분야로 관심을 확장하고 있습니다.
